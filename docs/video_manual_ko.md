# PyhgoShift LiveShow Dashboard 영상 매뉴얼

## 영상 목표

- 길이: 약 2분 20초
- 형식: 16:9, 1920×1080, 한국어 내레이션·자막
- 대상: 운영 담당자 및 신규 프로젝트 등록 담당자
- 핵심 메시지: Google Sheets의 작업 상태를 대시보드에서 5초 단위로 모니터링하고, 전환 완료 검증까지 한 화면에서 수행한다.

## 시연 전 준비

1. `npm install` 후 `npm run dev`로 대시보드를 실행한다.
2. 기본 화면은 데모 작업 목록으로 동작한다. 실제 시연 전에는 테스트용 Apps Script URL 또는 허가된 Google Sheets 웹 앱 URL을 준비한다.
3. 시연용 데이터는 여섯 단계 중 하나를 `progress`, 이전 단계를 `done`, 이후 단계를 `wait`로 준비한다.
4. URL 검증 장면을 촬영하려면 DNS 작업을 `done` 상태로 설정한다.
5. 완료 장면은 모든 URL 검증을 마친 상태에서 촬영한다.

## 실제 운영 절차

1. 프로젝트별 작업 시트를 준비한다. 작업 ID, 작업명, 단계, 상태, 진행률, DNS 여부, URL 검증 정보를 동일한 구조로 관리한다.
2. Apps Script를 웹 앱으로 배포하고, 읽기 전용 JSON 응답을 제공한다.
3. Master Router 시트에 활성 프로젝트, 프로젝트명, 설명, 해당 Apps Script 주소를 등록한다.
4. 대시보드의 설정 영역에 Apps Script 웹 앱 주소를 입력한다.
5. 상태가 `done`, `progress`, `wait` 및 진행률로 전달되는지 확인한다.
6. DNS 완료 후 URL 검증을 수행하고, 최종 완료 상태와 완료 알림을 확인한다.

## 주의사항

- 공개된 Apps Script URL에 민감한 운영 정보나 인증 정보가 포함되지 않도록 한다.
- 실제 운영 시트의 구조를 바꾸면 Apps Script 응답 형식과 대시보드 매핑을 함께 검증한다.
- 현재 소스의 일부 한글 문자열은 인코딩이 깨져 있으므로, 배포 전 사용자 노출 문구를 UTF-8 한국어로 정리해야 한다.
